# BC 2024 Provincial Election Tableau Dashboard

This project uses public Elections BC and DataBC results for the 2024 Provincial General Election.

No private voter data is used.

## What this shows

* Tableau dashboard design
* Public election data analysis
* KPI reporting
* Electoral district results
* Voting method analysis
* Source notes and context notes

## Files

* `workbook/BC_2024_Provincial_Election_Dashboard.twbx`
* `data/`

## Dashboard views

* Results Overview
* Explore by District

## Main metrics

* Electoral districts
* Registered voters
* Total votes cast
* Rejected ballots
* Voter turnout
* Seats won by party
* Popular vote by party
* Votes by voting method

## Source

Public Elections BC and DataBC 2024 Provincial General Election results.

This is a portfolio project for learning and analysis.
